## 我们是谁  
**Byte Pulse / 字节脉动** 是一个持续产出的技术与创作组织  

我们关注的不只是“能不能做”, 而是  
**做出来的东西是否真实.是否长期有价值**  

这里不追热点  
不堆概念  
更不为了“看起来很厉害”而存在 (￣▽￣)  

---

## 我们在做什么  
我们围绕数字世界中的实际问题进行探索和实践  

- 🧠 技术项目  
  - 工具类.实验性项目.实用型代码  
  - 注重可维护性.可扩展性和真实使用场景  

- 🎨 创作与表达  
  - 技术相关内容整理  
  - 产品思考.架构记录.学习沉淀  

- ⚙️ 探索与尝试  
  - 新技术方向的实践  
  - 尚不成熟但值得验证的想法  

不保证每个项目都成功  
但尽量保证每个项目都认真对待 (´･ω･`)  

---

## 我们的态度  
一些默认共识, 不写成口号  

- 🌱 长期主义  
  相信积累, 而不是短期刺激  

- 🧩 反对无意义复杂  
  简单是一种能力, 也是一种选择  

- 🔁 重视输出  
  想法只有被实践, 才会产生价值
